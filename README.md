# Systemy inspekcji wizualnej — laboratoria

Repozytorium z notatnikami do laboratoriów z przedmiotu *Systemy inspekcji wizualnej*.

## Struktura

- `labs/LabN/` — notatnik i materialy dla kolejnych laboratoriow
- `photos/` — wspolne obrazy/dane udostepnione do wykorzystania w zadaniach

## Srodowisko

Zarzadzane przez `uv` (Python 3.12, patrz `.python-version`).

```bash
uv sync
